# Brief Gamma. R3M7. Estabilització i tancament tècnic

## Regressió i còpia neta

Des d’una còpia neta i amb una BBDD de prova, seguix el README, reconstruïx les dades i guarda l’eixida d’una suite o checklist executada. Verifica els dos fluxos i els seus errors, la protecció d’accés i el correu d’R3M6. Revisa les responsabilitats. Si detectes una incidència, documenta símptoma, causa, correcció i prova posterior. Si no en detectes, registra les comprovacions executades.

## RA avaluat

- **RA avaluat**: `RA5`
- **CA avaluats**: `RA5.f`, `RA5.g`, `RA5.h`, `RA5.h`
- **RA de context**: `RA6.f`, `RA6.g`

Este microrepte genera nota només per al RA avaluat. Els RA de context poden aparéixer en el producte, però no es ponderen en esta rúbrica.


## Objectiu

Presentar el microrepte `R3M7`: tancar el repte amb README reproduïble, documentació de BBDD, dos fluxos, acció protegida, decisions, demo i backlog cap a `R4`.


## Contingut

- Codi: `R3M7`; sessió: `R3S7`.
- Diferència entre README real i relat embellit.
- Què ha d'incloure el tancament:
  - arrencada;
  - BBDD, migracions o equivalent i càrrega inicial reproduïble;
  - dos fluxos;
  - acció protegida i cas denegat;
  - decisions tècniques;
  - demo;
  - backlog;
  - possible recurs o endpoint per a `R4`.
- Incloure prova de còpia neta: `.env`, arrencada, migració, seeder, dos fluxos, auth i suite/checklist.
- Proposar una demo de 5–7 minuts amb cas positiu, error, canvi d'usuari i denegació.
- Mostrar l’estat migrat/adaptat/pendent i un recurs candidat a R4.
- Errors habituals: README genèric, instruccions que no funcionen, ocultar parts no migrades, no documentar BBDD.

## Límit

No implementar encara API; només preparar el pas a `R4`.

## Tancament: ampliació global

En R3M7 es recull una única proposta d’ampliació del repte complet (0–1), separada de la nota del microrepte. La presentació ha de mostrar les evidències i reservar la validació al professorat. Fórmula global: `0,9 × nucli ponderat + ampliació validada`. Sense revisió, estat pendent.
