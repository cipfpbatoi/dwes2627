# Brief Gamma. R3M4. Components de vista i manteniment d'un recurs

## RA avaluat

- **RA avaluat**: `RA8`
- **CA avaluats**: `RA8.f`, `RA8.g`
- **RA de context**: `RA5.e`, `RA5.f`, `RA5.g`, `RA5.h`, `RA6.c`, `RA6.d`, `RA6.f`

Este microrepte genera nota només per al RA avaluat. Els RA de context poden aparéixer en el producte, però no es ponderen en esta rúbrica.


## Objectiu

Presentar el microrepte `R3M4`: mantindre un recurs existent amb un component de vista reutilitzable, actualització `PUT/PATCH`, eliminació `DELETE` i persistència coherent.


## Contingut

- Codi: `R3M4`; sessió: `R3S4`.
- Progressió `GET/POST` d'R3M3 cap a `PUT/PATCH/DELETE` en R3M4.
- Diferència entre `PUT`, `PATCH`, `DELETE` i una transició d'estat.
- Limitació dels formularis HTML a `GET/POST` i mecanismes natius de *method override* o equivalents server-rendered.
- Què ha de construir:
  - component, parcial, macro o equivalent reutilitzat almenys en dos llocs;
  - actualització amb `PUT/PATCH` o equivalent documentat;
  - eliminació amb `DELETE` o equivalent documentat;
  - BBDD real;
  - CSRF, validació, error i `404` o equivalent;
  - regressió del primer flux.
- Explicar component amb entrada explícita, reutilització real i absència de duplicació HTML.
- Explicar operació atòmica i `rollback` quan canvien diverses files o registres relacionats.
- Incloure equivalències per a Laravel, Symfony, Django i NestJS sense exigir la mateixa sintaxi. En Django, diferenciar *template partials* de Django 6, `include ... with ... only` i `inclusion_tag` quan cal lògica Python.
- Incloure un exemple docent actualitzat amb edició, eliminació controlada, component reutilitzat i regressió d'R3M3.
- Errors habituals: comptar el *layout* com a component, canviar dades amb `GET`, confondre `DELETE` amb cancel·lar i trencar el primer flux.

## Límit

No demanar API, integració externa, autenticació, rols complexos ni un CRUD complet.
