# Brief Gamma. R1M2. Entorn executable, landing inicial i tancament de R1

## RA avaluat

- **RA avaluat**: `RA1`
- **CA avaluats**: `RA1b`, `RA1c`, `RA1d`, `RA1e`, `RA1f`, `RA1g`
- **RA de context**: cap

Este microrepte genera nota només per al RA avaluat. Els RA de context poden aparéixer en el producte, però no es ponderen en esta rúbrica.


## Objectiu

Crear o actualitzar una presentació de sessió o microrepte per a `R1M2`, centrada en entorn executable, landing inicial servida pel backend, documentació i checkpoint de pas a `R2`.

Ha de remarcar que `R1M2` continua sobre el mateix repositori individual assignat pel professorat iniciat en `R1M1`; no és el moment de crear un repositori nou.


## Contingut que ha d'incloure

- Què significa que l'entorn siga executable.
- Recuperar el repositori individual clonat en `R1M1` i comprovar que el remot és el correcte.
- Peces mínimes: servidor web, runtime, projecte, landing inicial i comprovació tècnica.
- Paper de Docker si s'usa.
- Confirmar o ajustar la decisió tècnica orientativa de `R1M1`.
- Crear una landing inicial amb HTML i CSS senzill, amb contingut propi del producte, servida pel backend.
- Explicar que `/health` o equivalent és només comprovació tècnica i no substitueix la landing.
- Què ha de demostrar l'alumnat.
- Com documentar README, decisions, incidències i evidències dins del repositori.
- Evidències mínimes: URL de la landing, captura o log, comprovació d'arrencada i README reproduïble.
- Errors habituals: tindre fitxers però no poder executar, captures sense explicació, entorn copiat sense entendre.
- Checklist final.

## Límit

No convertir esta presentació en una guia completa de Docker ni en una introducció a framework. L'objectiu és arrancar i verificar una base mínima amb una primera entrada visible del producte. La IA pot ajudar a preparar HTML/CSS, però l'alumnat ha de verificar que la pàgina està servida pel backend i pot explicar què ha acceptat o modificat.

## Tancament: ampliació global

En R1M2 es recull una única proposta d’ampliació del repte complet (0–1), separada de la nota del microrepte. La presentació ha de mostrar les evidències i reservar la validació al professorat. Fórmula global: `0,9 × nucli ponderat + ampliació validada`. Sense revisió, estat pendent.

## Procediment Git que ha de mostrar Gamma

El professorat crea el repositori i convida l’alumne. No s’usa GitHub Classroom ni es clona la plantilla. Només hi ha `main` i una branca per microrepte; no crear branques de repte ni exigir pull requests.

Des de la còpia local, amb el treball anterior guardat:

```bash
git switch main
git pull --ff-only origin main
git switch -c microrepte/r1m2
```

Treballar, comprovar i guardar només els fitxers de l’entrega amb `git add` i `git commit`. Pujar la branca:

```bash
git push -u origin microrepte/r1m2
```

Per entregar, integrar el treball personalment:

```bash
git switch main
git pull --ff-only origin main
git merge --no-edit microrepte/r1m2
git push origin main
```

L’autocorrecció llig `main`: pujar només la branca del microrepte no completa l’entrega. Conservar les branques anteriors per consultar-les. Per reprendre un microrepte ja començat, usar `git switch microrepte/r1m2`, sense tornar a crear-lo. Davant d’un conflicte, demanar ajuda; no forçar ni descartar treball.

## Retorn, consolidació i ús d’IA

Els microreptes són treball d’aula consecutiu. El retorn i la correcció guiada ajuden a continuar el projecte; no són una recuperació ni una nova qualificació individual del microrepte. Només es recupera el repte complet segons el procediment docent. Les fitxes de consolidació es consulten quan el professorat les publique.

La IA pot explicar teoria i donar pistes sobre un intent propi. No pot implementar la configuració avaluable, el backend ni les proves en lloc de l’alumne. L’excepció d’HTML/CSS es limita a presentació estàtica: camps, `name`, `method`, `action` i processament s’han d’entendre i decidir personalment. Registre únic en `docs/ai-log.md`, amb guia i apartat «El meu registre». Si no hi ha ús d’IA, declarar-ho sense inventar consultes.
