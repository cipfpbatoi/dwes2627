# Brief Gamma. R1M1. Model client/servidor i elecció guiada de stack

## RA avaluat

- **RA avaluat**: `RA1`
- **CA avaluats**: `RA1a`, `RA1b`, `RA1c`, `RA1g`
- **RA de context**: cap

Este microrepte genera nota només per al RA avaluat. Els RA de context poden aparéixer en el producte, però no es ponderen en esta rúbrica.


## Objectiu

Crear o actualitzar una presentació de microrepte per a `R1M1`, centrada en entendre el model client/servidor, el paper del backend i una primera decisió guiada de stack.

També ha de deixar clar el primer pas operatiu del curs: acceptar l'enllaç de GitHub Classroom, clonar el repositori individual i fer un primer `push` amb el `README.md` inicial.


## Contingut que ha d'incloure

- Codi del microrepte: `R1M1`.
- Què ha de construir l'alumnat: fitxa o evidència equivalent d'exploració tècnica inicial.
- Quan i com es prepara el repositori: en `R1S1`, amb l'enllaç de GitHub Classroom donat pel professorat.
- Advertència explícita: no clonar el repositori base directament i no crear un repositori nou.
- Primer `push`: `README.md` amb microrepte actual, projecte base, flux client/servidor i decisió inicial de stack.
- Diferència entre client, servidor i backend.
- Què s'executa al navegador i què s'executa al servidor.
- Comparació acotada de stack.
- Evidències mínimes.
- Criteris d'èxit.
- Què no és suficient.
- Checklist final.

## Límit

No demanar encara entorn executable ni punt d'entrada funcional. Això pertany a `R1M2`. En `R1M1` només es comprova que el repositori de Classroom està operatiu i que conté la primera evidència documental.
