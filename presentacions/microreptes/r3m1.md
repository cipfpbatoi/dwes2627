# Brief Gamma. R3M1. Arrencada del nou projecte

## RA avaluat

- **RA avaluat**: `RA5`
- **CA avaluats**: `RA5.a`, `RA5.b`, `RA5.c`, `RA5.d`, `RA5.e`
- **RA de context**: `RA8.c`

Este microrepte genera nota només per al RA avaluat. Els RA de context poden aparéixer en el producte, però no es ponderen en esta rúbrica.


## Objectiu

Presentar el microrepte `R3M1`: crear una base en framework arrancable, amb Docker o equivalent, `.env.example`, ruta inicial, comparativa de stack i abast dels dos fluxos de `R3`.


## Contingut

- Codi: `R3M1`; sessió: `R3S1`.
- Per què `R3` no és migrar tota l'aplicació.
- Què vol dir projecte arrancable en framework.
- Què ha de construir:
  - stack triat;
  - Docker o entorn equivalent;
  - `.env.example`;
  - ruta inicial o `healthcheck`;
  - comparativa curta;
  - esquema abans/després;
  - issue de `R3` amb dos fluxos.
- Evidències i checklist.
- Incloure un requadre específic «Si tries Node.js» que deixe clar:
  - `Node.js` és el runtime i `NestJS` és el framework base;
  - el mínim és projecte arrancable, mòdul, controlador, ruta i resposta
    comprovable;
  - Docker o equivalent, `.env.example`, comparativa, esquema abans/després i
    dos casos d'ús són les mateixes evidències que en els altres stacks;
  - separar la resposta en un `service` o afegir una prova HTTP és útil, però no
    obligatori en `R3M1`;
  - BBDD, autenticació i fluxos complets queden per als microreptes següents.
- Errors habituals: framework que no arranca, comparativa genèrica, secrets en `.env.example`, no declarar fluxos.

## Límit

No demanar encara BBDD, migracions/fixtures/seeders ni flux complet.
