# R3M2. Persistència mínima amb migracions, fixtures/seeders o equivalent

## RA avaluat

- **RA avaluat**: `RA6`
- **CA avaluats**: `RA6.a`, `RA6.b`, `RA6.c`, `RA6.d`, `RA6.e`
- **RA de context**: `RA5.f`

Este microrepte genera nota només per al RA avaluat. Els RA de context poden aparéixer en el producte, però no es ponderen en esta rúbrica.


## Visor del microrepte

| Camp | Valor |
|---|---|
| Repte | `R3` |
| Sessió | `R3S2` |
| Microrepte | `R3M2` |
| Autocorrecció | `r3-s02-persistencia-minima-migrations-seeders` |

## Producte mínim esperat

Una persistència real i reconstruïble que prepare els dos fluxos de R3. El model ha de ser mínim: només les entitats, camps i relacions que s'usaran.

Ha d'incloure:

- connexió a BBDD configurada amb variables d'entorn;
- models o entitats del domini;
- migracions versionades o mecanisme equivalent;
- fixtures, seeders o script de càrrega reproduïble;
- dades recognoscibles vinculades als fluxos;
- lectura ORM real integrada en un llistat, detall, filtre o resposta;
- instruccions per reconstruir i carregar des d'una BBDD buida.

## Criteris i pesos

| Dimensió | Pes | Què es comprovarà |
|---|---:|---|
| Resolució funcional | `50%` | BBDD real amb migracions o equivalent, dades reproduïbles i lectura de dades. |
| Verificació | `10%` | Reset o reconstrucció de BBDD, càrrega i lectura comprovades. |
| Traçabilitat | `5%` | Commits o registre de model, migracions/càrrega de dades i prova. |
| Documentació | `10%` | Com crear BBDD, carregar dades i quin flux alimenten. |
| Ús d'IA | `5%` | Registre i validació de propostes de camps, migracions o càrrega inicial. |
| Qualitat tècnica | `20%` | Esquema mínim, coherent i no manual. |

## Evidències requerides

| Evidència | Mínim acceptable | Senyal esperat |
|---|---|---|
| Connexió | Configuració funcional per entorn | L'aplicació connecta sense secrets versionats. |
| Esquema | Migracions o equivalent versionat | Una BBDD buida es pot crear sense operacions manuals. |
| Model | Entitats i relacions mínimes | Els camps responen als fluxos triats. |
| Dades inicials | Fixture/seeder/script executable | Crea dades recognoscibles i repetibles. |
| Lectura | Consulta ORM o capa de dades real | No prové d'un array ni només d'una consola. |
| Ús | Llistat, detall, filtre o resposta | Les dades arriben a una peça visible de l'aplicació. |
| Documentació | Ordres de reset, migració i càrrega | Una altra persona pot reproduir el procés. |
| Traçabilitat | Commits o registre equivalent | Distingix model, migració, dades i verificació. |

## Comprovació reproduïble

La seqüència ha de poder demostrar:

```text
BBDD buida → migracions → dades inicials → consulta real → resposta amb dades
```

1. Reinicia o crea una BBDD de prova buida.
2. Executa les migracions.
3. Carrega fixtures/seeders o equivalent.
4. Comprova el recompte i algunes dades recognoscibles.
5. Obri la ruta que les consulta.
6. Canvia una dada en BBDD o en la càrrega i comprova que la resposta també canvia.

## Què no és suficient

- Les migracions internes del framework sense cap taula del domini.
- Crear taules manualment amb phpMyAdmin o una eina semblant.
- Tindre models sense migracions versionades.
- Un seeder buit o dades carregades a mà.
- Consultar en shell sense usar després les dades en l'aplicació.
- Mostrar arrays fixos en el controlador o la vista.
- Documentar ordres que no s'han executat.

## Regles que limiten la valoració

- Sense BBDD real, la puntuació màxima recomanada és `5`.
- Sense migracions o equivalent versionat, la màxima recomanada és `6`.
- Sense càrrega reproduïble, la màxima recomanada és `7`.
- Sense lectura real, la màxima recomanada és `7`.
- Les dades només manuals penalitzen verificació i documentació.

## Ampliació opcional

Només després del mínim:

- una relació addicional utilitzada realment;
- factory per a proves;
- restriccions de BBDD coherents amb el domini;
- prova automàtica de reconstrucció, càrrega o lectura.

No cal modelar tot el producte ni afegir relacions que els fluxos no usaran.

## Fora d'abast

No es demanen encara dos fluxos complets ni API.

Tampoc s'exigixen encara formulari complet, autenticació, rols o permisos avançats.

## Correspondència amb l'exemple docent

La branca [`r3m2`](https://github.com/batoi-dwes-2026/microreptes-c-igomis/tree/r3m2) incorpora models `Servei` i `Intercanvi`, migracions, seeder determinista i un catàleg que consulta Eloquent. Compara-la amb `r3m1` per identificar només el canvi de persistència.

## Checklist abans d'entregar

- [ ] La configuració usa variables d'entorn.
- [ ] Les migracions creen l'esquema des de zero.
- [ ] El model és mínim i respon als fluxos.
- [ ] La càrrega inicial és executable i reproduïble.
- [ ] Les dades no s'han introduït només a mà.
- [ ] Una ruta consulta i mostra dades reals.
- [ ] He documentat reset, migració, càrrega i lectura.
- [ ] He guardat evidències/commits i registre d'IA si correspon.
