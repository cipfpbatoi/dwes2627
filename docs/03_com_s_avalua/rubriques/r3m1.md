# R3M1. Arrencada del nou projecte

## RA avaluat

- **RA avaluat**: `RA5`
- **CA avaluats**: `RA5.a`, `RA5.b`, `RA5.c`, `RA5.d`, `RA5.e`
- **RA de context**: `RA8.c`

Este microrepte genera nota només per al RA avaluat. Els RA de context poden aparéixer en el producte, però no es ponderen en esta rúbrica.


## Visor del microrepte

| Camp | Valor |
|---|---|
| Repte | `R3` |
| Sessió | `R3S1` |
| Microrepte | `R3M1` |
| Autocorrecció | `r3-s01-arrencada-nou-projecte` |

## Producte mínim esperat

Una base real en `Laravel`, `Symfony`, `Django` o `NestJS` —o una via excepcional autoritzada— que una altra persona puga arrancar seguint les instruccions del repositori.

Ha d'incloure:

- projecte del framework dins del repositori;
- Docker, Compose o entorn equivalent documentat;
- `.env.example` o instruccions de configuració sense secrets;
- ruta inicial, portada mínima o `healthcheck` gestionat pel framework;
- comparació curta amb una alternativa;
- esquema abans/després entre R2 i R3;
- dos casos d'ús acotats, indicant quin ve d'R2 i quin serà server-rendered.

## Criteris i pesos

| Dimensió | Pes | Què es comprovarà |
|---|---:|---|
| Resolució funcional | `50%` | Projecte en framework arrancable, configuració mínima i ruta inicial funcional. |
| Verificació | `10%` | Arrencada i ruta comprovades seguint instruccions. |
| Traçabilitat | `5%` | Commits o registre d'inici, arrencada i tancament. |
| Documentació | `10%` | Comparativa, esquema abans/després, `.env.example` i dos casos d'ús. |
| Ús d'IA | `5%` | Registre i verificació si la IA ha intervingut. |
| Qualitat tècnica | `20%` | Ús real de convencions del framework i absència de secrets versionats. |

## Evidències requerides

| Evidència | Mínim acceptable | Senyal esperat |
|---|---|---|
| Projecte | Framework real versionat | No és una carpeta buida ni una explicació teòrica. |
| Arrencada | Ordre reproduïble amb Docker o equivalent | El servei inicia i no depén de passos ocults. |
| Configuració | `.env.example` o instruccions | No conté claus ni contrasenyes reals. |
| Ruta inicial | URL o ordre de comprovació | La resposta prové del framework i es pot repetir. |
| Comparativa | Stack triat contra una alternativa | Justifica un avantatge concret per al projecte. |
| Mapa R2→R3 | Esquema curt de responsabilitats | Relaciona entrada, controlador, dades i presentació. |
| Abast | Dos casos d'ús de R3 | Estan retallats i no prometen migrar tota l'aplicació. |
| Traçabilitat | Commits o registre equivalent | Permet identificar inici, arrencada i tancament. |

## Comprovació reproduïble

1. Clona o prepara una còpia neta.
2. Crea la configuració local a partir de l'exemple.
3. Executa l'ordre documentada d'arrencada.
4. Obri la ruta inicial i comprova la resposta.
5. Localitza la ruta i el controlador, view o manejador equivalent.
6. Revisa que els dos fluxos i el mapa R2→R3 estiguen documentats.

## Què no és suficient

- Instal·lar dependències sense poder arrancar.
- Una portada HTML que no passa pel framework.
- Una comparativa genèrica copiada sense decisió pròpia.
- Declarar “migraré tot R2” sense dos fluxos concrets.
- Versionar `.env`, secrets o credencials reals.
- Mostrar una captura sense instruccions reproduïbles.

## Regles que limiten la valoració

- Sense projecte arrancable, la puntuació màxima recomanada és `5`.
- Sense ruta inicial o `healthcheck`, la màxima recomanada és `6`.
- Sense `.env.example` o instruccions, la màxima recomanada és `7`.
- Sense els dos casos d'ús declarats, la màxima recomanada és `8`.
- Els secrets reals versionats requerixen revisió docent.

## Ampliació opcional

Només després del mínim:

- prova HTTP de la ruta inicial;
- `healthcheck` del contenidor;
- segona forma d'execució ben documentada.

L'ampliació no compensa una arrencada que no funciona.

## Fora d'abast

No es demana encara BBDD, migracions/fixtures/seeders, flux complet ni API.
