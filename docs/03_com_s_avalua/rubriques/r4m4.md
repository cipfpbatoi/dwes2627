# Rúbrica R4M4. Consum real del servei

## RA avaluat

- **RA avaluat**: `RA7`
- **CA avaluats**: `RA7.f`, `RA7.g`
- **RA de context**: cap

Este microrepte genera nota només per al RA avaluat. Els RA de context poden aparéixer en el producte, però no es ponderen en esta rúbrica.


| Dimensió | Pes | Què es comprova |
|---|---:|---|
| Resolució funcional | `50%` | Consumidor mínim, col·lecció o script que fa peticions reals. |
| Verificació | `10%` | Cas correcte i cas d'error o invàlid. |
| Traçabilitat | `5%` | Evidències del consumidor i de les proves. |
| Documentació | `10%` | Instruccions per reproduir el consum. |
| Ús d'IA | `5%` | Si hi ha IA, consumidor adaptat i verificat. |
| Qualitat tècnica | `20%` | El consumidor llig resposta, envia credencial si cal i tracta error mínim. |

## Regles dures

- Sense consumidor o prova equivalent, màxim recomanat `5`.
- Sense cas d'error, màxim recomanat `7`.
- Sense instruccions de reproducció, màxim recomanat `8`.
