# R2M7. Prova de flux HTTP, depuració i checkpoint tècnic

## RA avaluat

- **RA avaluat**: `RA4`
- **CA avaluats**: `RA4.f`
- **RA de context**: cap

Este microrepte genera nota només per al RA avaluat.

## Què es valora

Es valora que el flux de `R2` deixe de dependre d'una demo oral i quede automatitzat com una prova HTTP reproduïble, amb incidències registrades i documentació d'execució.

No es demana encara una suite completa ni testing professional.

## Evidències mínimes

- `tests/flux-r2.php` o una prova HTTP equivalent en Bash, Python o Java.
- Accés protegit sense autenticar denegat.
- Login incorrecte denegat i login demo correcte acceptat.
- Sessió o token conservat entre peticions.
- Operació protegida autenticada permesa.
- Logout o invalidació i nou intent denegat.
- Assercions sobre codis, redireccions o textos estables.
- Codi d'eixida diferent de `0` quan falla qualsevol expectativa.
- Una única ordre d'execució i una eixida real en `evidence/r2m7/verificacio.txt` o equivalent.
- Incidències detectades o confirmació explícita que no n'hi ha.
- `README.md` o guia de reproducció actualitzada.

## Rúbrica

| Dimensió | Pes | Què ha d'estar clar |
|---|---:|---|
| Resolució funcional | `50%` | La prova executa els sis passos, conserva la identitat i comprova denegació, accés permés i invalidació. |
| Verificació | `10%` | Les assercions detecten resultats inesperats i el procés retorna error quan toca. |
| Traçabilitat | `5%` | Hi ha incidències, correccions o registre de checkpoint. |
| Documentació | `10%` | Una ordre, requisits, dades demo i eixida real permeten repetir la prova. |
| Ús d'IA | `5%` | Si s'ha usat IA, s'ha verificat el resultat de les proves. |
| Qualitat tècnica | `20%` | URL configurable, estat temporal, assercions estables i neteja fan la prova fiable. |

## Regles dures

- Sense prova HTTP executable amb comprovacions automàtiques, màxim recomanat `6`.
- Una ordre `curl` que només imprimix, una col·lecció sense assercions o una taula manual no compten com a prova automàtica.
- Si falta la denegació inicial, l'operació protegida o la denegació posterior al logout, màxim recomanat `8`.
- Sense instruccions d'execució o sense eixida real, màxim recomanat `8`.
- Una prova unitària amb `PHPUnit`, `pytest` o `JUnit` no substituïx el flux HTTP de `R2M7`.
- PHP és la via explicada a classe, però una entrega `.sh` en Bash o una alternativa equivalent no es penalitza si complix el mateix recorregut i les mateixes comprovacions.
- Si el checkpoint trenca un flux anterior, cal corregir abans de tancar `R2`.
