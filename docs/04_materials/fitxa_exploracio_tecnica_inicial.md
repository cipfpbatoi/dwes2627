# Exploració tècnica inicial

Usa esta fitxa curta dins del microrepte `R1M1` del `Repte 1` per deixar visible què has investigat, com entens el model client/servidor i quina orientació tècnica inicial proposes.

Es pot omplir amb ajuda d'IA, però no busca una comparativa exhaustiva. Busca comprensió inicial, criteri tècnic i dubtes ben detectats.

Esta decisió **no tanca encara el framework definitiu del curs**. En `R1M1` proposes una base tècnica inicial. En `R1M2` la confirmaràs o ajustaràs quan muntes l'entorn executable. La tria real de framework, si toca comparar `Laravel`, `Symfony` o `NestJS` amb més profunditat, arribarà a partir de `R3`.

No cal adjuntar captures de totes les converses amb IA.
