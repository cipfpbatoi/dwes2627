# Fitxes de consolidació després de classe

El professorat publicarà ací les fitxes després de treballar cada microrepte. Inclouran exemples explicats, errors habituals, una pràctica curta i comprovacions de comprensió. La publicació és comuna per a tot l’alumnat.

Són materials de suport per continuar aprenent, sense nova entrega ni recuperació individual dels microreptes. La recuperació correspon al repte complet.
