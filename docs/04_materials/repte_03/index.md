# Guies de suport del Repte 3

L'enunciat principal està en [Repte 3](../../02_reptes/repte_03.md). Esta pàgina només ordena les guies que t'ajuden a treballar `R3` a classe sense quedar-te en teoria sobre `MVC`.

En `R3` has de reconstruir el projecte en framework i deixar una base real:

- Docker funcional
- BBDD creada per migracions o equivalent
- dades inicials amb fixtures/seeders o script equivalent
- `2` casos d'ús funcionals
- almenys `1` cas server-rendered amb vista o plantilla
- acció protegida amb autenticació i autorització del framework
- validació, errors i proves mínimes
- README curt d'arrencada i ús

## Com usar estes guies

- [Fitxa general](fitxa_general.md): resum ampliat de què és `R3`, què has de construir i què no es demana.
- [Guia operativa dels microreptes](microreptes.md): desenvolupament pràctic de `R3M1` a `R3M7`, alineat amb la pàgina del repte.
- [Suport tècnic mínim](suport_tecnic.md): ajuda per ubicar rutes, controladors, vistes, models, BBDD, migracions, fixtures/seeders o scripts, Docker i proves.
- [Checklists](checklists.md): comprovacions abans de donar per tancat cada tram.

## Lectura recomanada

1. Llig primer la [fitxa general](fitxa_general.md).
2. Treballa cada microrepte amb la [guia operativa](microreptes.md).
3. Consulta [suport tècnic](suport_tecnic.md) quan no sàpies on va cada peça.
4. Abans d'entregar, passa els [checklists](checklists.md).
