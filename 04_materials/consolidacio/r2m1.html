    R2M1. Consolidació: del formulari a la validació en servidor¶

    Esta fitxa es consulta després del treball d’aula. Servix per entendre errors i preparar R2M2; no és una nova entrega ni recupera individualment R2M1. La recuperació, si cal, correspon al repte complet.

    1. Què cal entendre¶

    • El navegador envia els controls que tenen name; el servidor llig les dades de la petició.
    • Un camp de text buit sol arribar com ''; un checkbox desmarcat no envia el seu nom. Cal tractar l’absència sense provocar avisos.
    • El servidor ha de prendre la decisió de validació i mostrar un error o una resposta correcta. required en HTML no substituïx eixa decisió.

    2. Exemple mínim explicat¶

    El cas és una inscripció a una visita del centre. És un exemple per entendre el procés; adapta l’aprenentatge a l’acció real del teu projecte.

    Guarda el fragment en visita.php. Des de la carpeta del fitxer, executa php -S localhost:8000 i obri http://localhost:8000/visita.php. Si uses l’entorn de classe, accedix a la ruta equivalent.

    <?php
$missatge = '';
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    // Els controls normals arriben com a text. Tractem absències i tipus inesperats.
    $nomRebut = $_POST['nom'] ?? '';
    $nom = is_string($nomRebut) ? trim($nomRebut) : '';
    $torn = $_POST['torn'] ?? '';
    $avisos = ($_POST['avisos'] ?? '') === 'si';

    // Una condició simple és suficient per modelar la validació bàsica.
    if ($nom === '') {
        $missatge = 'Escriu el teu nom.';
    } elseif (!in_array($torn, ['mati', 'vesprada'], true)) {
        $missatge = 'Tria un torn vàlid.';
    } else {
        $missatge = 'Sol·licitud rebuda de ' . $nom . '. Torn: ' . $torn;
        $missatge .= $avisos ? '. Vol avisos.' : '. No vol avisos.';
    }
}
?>
<!doctype html>
<html lang="ca">
<meta charset="utf-8">
<title>Visita al centre</title>
<h1>Sol·licitar una visita</h1>
<form method="post">
    <label>Nom <input name="nom" type="text"></label>
    <label>Torn
        <select name="torn">
            <option value="mati">Matí</option>
            <option value="vesprada">Vesprada</option>
        </select>
    </label>
    <label><input type="checkbox" name="avisos" value="si"> Vull avisos</label>
    <button type="submit">Enviar</button>
</form>
<p><?= htmlspecialchars($missatge, ENT_QUOTES, 'UTF-8') ?></p>
</html>

    El bloc POST evita validar quan encara només estem obrint la pàgina. ?? dona un valor si una dada no ha arribat; trim tracta un nom amb espais com a buit. El torn és una dada classificada que després pot alimentar una regla. El checkbox representa una preferència opcional: desmarcat és un cas correcte, no un error.

    La comprovació del torn mostra com contrastar una opció amb una llista permesa. No implica que en R2M1 calguera una validació exhaustiva de tots els camps: el mínim continua sent una condició simple en servidor, error visible i reenviament corregit.

    htmlspecialchars permet mostrar el missatge com a text. El formulari queda buit després d’enviar: és deliberat en este exemple. Conservar valors i guardar funcionalment la dada correcta són el pas següent de R2M2. «Sol·licitud rebuda» no significa que s’haja guardat res.

    Si treballes amb Python¶

    En Flask, llig els camps amb request.form.get('nom', ''), request.form.get('torn', '') i comprova el checkbox amb request.form.get('avisos') == 'si'. Fes la mateixa validació en la funció de la ruta i passa el missatge a render_template. Jinja escapa {{ missatge }} per defecte; no uses |safe amb dades de l’usuari.

    3. Errors habituals¶

    Què observes Causa possible Com comprovar-ho
    La dada no apareix en $_POST Falta name o el formulari usa GET. Revisa el control i la petició enviada en la pestanya de xarxa.
    Avís de clau inexistent Es llig directament el checkbox absent. Desmarca’l i comprova el valor per defecte amb ??.
    El formulari rebutja dades només en el navegador Només hi ha required o JavaScript. Envia una petició directa amb el nom buit i comprova la resposta del servidor.
    Un nom amb espais es considera vàlid No es normalitza abans de comparar. Prova tres espais i revisa l’ús de trim.
    Es mostra codi HTML en lloc de text El text variable no està escapat. Prova el nom Aina <equip>: les etiquetes han de veure’s com a text.
    S’espera que la inscripció reaparega després Es confon rebre amb guardar. Revisa que este exemple no escriu en cap magatzem.

    4. Modificació curta per practicar¶

    Afegix un torn dissabte. Actualitza tant l’opció HTML com els valors permesos del servidor. Prova primer què passa si només canvies l’HTML i explica per què apareix l’error. Després completa el canvi i comprova el cas correcte.

    És pràctica de consolidació, sense nou lliurament avaluable. Conserva notes del que has corregit i de les proves; si uses IA, registra només la consulta real i com l’has contrastada.

    5. Comprova que ho entens¶

    Cas Resultat esperat
    Obrir la pàgina amb GET Formulari visible, sense error inicial.
    Nom buit, torn matí «Escriu el teu nom.»
    Nom amb tres espais Mateix error de nom.
    Aina, matí, avisos desmarcats Sol·licitud rebuda; no vol avisos.
    Aina, vesprada, avisos marcats Sol·licitud rebuda; vol avisos.
    Torn manipulat a nit «Tria un torn vàlid.»

    Pots comprovar la validació en servidor amb una petició directa:

    curl -s -d 'nom=&torn=mati' http://localhost:8000/visita.php

    Assenyala on apareix l’error en la resposta. Explica també per què avisos pot no existir i què canviaria si llevàrem la condició del servidor. Predir el resultat abans d’executar ajuda a distingir comprensió de còpia.

    6. Què necessites per a R2M2¶

    Has de poder enviar dades, identificar on es lligen i reproduir un cas incorrecte i un de correcte. En R2M2 aprofitarem eixes dades per reconstruir el formulari sense perdre el que l’usuari ja havia escrit i per guardar funcionalment el cas vàlid.

    Si encara et bloqueges, demana ajuda en el tram de consolidació inicial. Corregir la base et permet continuar; no canvia automàticament la qualificació del treball d’aula anterior.
